Torder Note —— 便签用字体子集的来源与许可

本文件对应的字体：src/assets/fonts/TorderNote-Regular.woff2

来源：小赖字体 / Xiaolai，LXGW（https://github.com/lxgw/kose-font），
      Version 3.126（2025-09-10）。原始文件 Xiaolai-Regular.ttf 共
      22,220,806 字节，与官方 release 资产逐字节一致（未改动的上游版本）。
      字形设计基于 Seto Font（濑尾希砂美 / Nozomi Seto，
      https://ja.osdn.net/projects/setofont/）。

修改：按 GB2312 汉字表（6,763 字）+ 拉丁/标点/全角区子集化，得 8,175 字形、
      1,632,172 字节；保留 TrueType 字节码 hinting（fpgm/prep/cvt，小字号
      清晰度靠它）；家族名改为 "Torder Note"。
      上游 OFL.txt 未声明 Reserved Font Name，改名是为了让本项目的修改版
      与用户可能自装的完整 Xiaolai 区分开，便于调试与回退。
      生成命令（fontTools 4.63，码点表为逗号分隔的 U+XXXX / U+XXXX-YYYY）：
        pyftsubset Xiaolai-Regular.ttf --flavor=woff2
          --unicodes-file=<GB2312 + 拉丁/标点/全角码点表>
          --name-IDs=0,1,2,3,4,5,6,13,14
          --output-file=TorderNote-Regular.woff2

许可：SIL Open Font License, Version 1.1（原文见下）。字体及其修改版必须以
      本许可分发、不得单独出售；用该字体排版的文档不受此许可约束。
      便签中未被本子集覆盖的字符（生僻字、扩展 A/B 等）按 CSS 字体回退规则
      落到 Frex Sans GB / Noto Sans SC / 系统字体，不构成对这些字体的再分发。
